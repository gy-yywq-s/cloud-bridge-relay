# Crew app-icon candidates

- **a — Formation:** Four linked member nodes form a coordinated diamond, with the larger ringed node acting as manager.
- **b — Interlock:** Three bold, interlocking links represent separate coding sessions operating as one chain.
- **c — Rowing crew:** Four members pull in parallel from a shared boat, with a larger lead member setting direction.
- **d — Shared board:** Four members gather around a central task board, with the ringed owner at the head.
- **e — Crew mail:** Overlapping conversation/mail shapes carry three member markers through a shared channel.
- **f — Member “c”:** Five rounded member segments form a lowercase “c,” capped by a checked manager node.
